# 제품 퀴즈 (Product Quiz)

리피토 · 리피토플러스 · 노바스크 · 리리카 · 쎄레브렉스 제품 학습용 퀴즈 사이트입니다.
**하루 5문제**를 풀며 포인트를 쌓는 형태로 만들어졌습니다.

## 주요 기능

- **하루 5문제**: 날짜를 기준으로 문제 은행에서 5문제가 자동 선택됩니다. (같은 날에는 모두 동일한 세트)
- **포인트 적립**
  - 정답당 **20점**
  - 5문제 모두 정답 시 **올클리어 보너스 +30점**
  - 연속 학습(스트릭) 1일당 **+5점** (최대 +50점)
- **연속 학습 스트릭**: 매일 학습하면 스트릭이 올라가고, 하루 건너뛰면 초기화됩니다.
- **정답 해설 & 리뷰**: 각 문제마다 해설을 제공하고, 완료 후 오늘의 문제를 다시 볼 수 있습니다.
- **진행 저장**: 브라우저 `localStorage`에 저장되어 새로고침해도 이어집니다. (별도 서버 불필요)

## 실행 방법

정적 사이트이므로 서버가 필요 없습니다.

```bash
# 방법 1: 파일을 브라우저에서 바로 열기
open index.html

# 방법 2: 간단한 로컬 서버
python3 -m http.server 8000
# → http://localhost:8000 접속
```

GitHub Pages 등 정적 호스팅에 그대로 배포할 수 있습니다.

## 문제 추가/수정

`questions.js` 파일의 `QUESTION_BANK` 배열에 항목을 추가하면 됩니다.

```js
{
  id: 100,                 // 고유 번호(중복 금지)
  drug: "리피토",           // 제품명 태그
  q: "질문 내용",
  options: ["보기1", "보기2", "보기3", "보기4"],
  answer: 0,               // 정답 인덱스(0부터)
  explain: "정답 해설",
}
```

문제 수가 많아질수록 매일 더 다양한 문제가 출제됩니다.

## 파일 구성

| 파일           | 설명                                    |
| -------------- | --------------------------------------- |
| `index.html`   | 화면 구조                               |
| `styles.css`   | 스타일(다크 테마, 모바일 대응)          |
| `app.js`       | 퀴즈 진행·포인트·스트릭 로직            |
| `questions.js` | 문제 은행(데이터)                        |
