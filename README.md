# 제품 퀴즈 (Product Quiz)

리피토 · 리피토플러스 · 노바스크 · 리리카 · 쎄레브렉스 제품 학습용 퀴즈 사이트입니다.
**하루 5문제**를 풀며 포인트를 쌓는 형태로 만들어졌습니다.

## 주요 기능

- **하루 5문제**: 프로필별로 매일 최초 접속 시 전체 문제 은행에서 5문제를 무작위로 선택하고 순서도 섞습니다. 같은 날의 세트는 저장되어 새로고침·이어풀기 시 유지됩니다.
- **포인트 적립**
  - 정답당 **20점**
  - 5문제 모두 정답 시 **올클리어 보너스 +30점**
  - 연속 학습(스트릭) 1일당 **+5점** (최대 +50점)
- **연속 학습 스트릭**: 매일 학습하면 스트릭이 올라가고, 하루 건너뛰면 초기화됩니다.
- **정답 해설 & 리뷰**: 각 문제마다 해설을 제공하고, 완료 후 오늘의 문제를 다시 볼 수 있습니다.
- **진행 저장**: 브라우저 `localStorage`에 저장되어 새로고침해도 이어집니다. (별도 서버 불필요)

## 실행 방법

정적 사이트이므로 서버가 필요 없습니다.

```bash
# 방법 1: 파일을 브라우저에서 바로 열기
open index.html

# 방법 2: 간단한 로컬 서버
python3 -m http.server 8000
# → http://localhost:8000 접속
```

GitHub Pages 등 정적 호스팅에 그대로 배포할 수 있습니다.

## 문제 추가/수정

`questions.js` 파일의 `QUESTION_BANK` 배열에 항목을 추가하면 됩니다.

```js
{
  id: 100,                 // 고유 번호(중복 금지)
  drug: "리피토",           // 제품명 태그
  q: "질문 내용",
  options: ["보기1", "보기2", "보기3", "보기4"],
  answer: 0,               // 정답 인덱스(0부터)
  explain: "정답 해설",
}
```

문제 수가 많아질수록 매일 더 다양한 문제가 출제됩니다.

## 확장 학습 기능

- 총 70문제: 제품별 14문제. 기존 50문제와 국내 진료지침 적용 20문제(품목별 4문제).
- 제품 선택 연습: 전체 70문제 또는 제품별 14문제. 진행은 프로필별로 저장하며 일일 퀴즈로 돌아가면 연습 세션을 종료합니다.
- 오답 노트: 틀린 문제, 최근 선택, 누적 오답 횟수, 해설 저장. 전체 미해결 또는 개별 문제 재도전. 정답 시 복습 완료, 이후 오답 시 다시 미해결.
- 제품별 정답률: 업데이트 이후 모든 모드의 제출 횟수 기준. 반복 풀이도 집계하며 기존 전체 정답률은 완료한 일일 퀴즈 기준을 유지합니다.
- 연습과 재도전은 포인트·스트릭·일일 완료 횟수를 변경하지 않습니다.
- 일일 문제 ID를 저장하여 문제 은행 변경에도 진행 중 세트를 유지합니다. 기존 당일 기록은 원래 28문제 세트로 복원합니다.
- 모든 70문제의 해설·결과 리뷰·오답 노트에서 해당 제품의 국내 허가사항(비아트리스 코리아 공개 제품설명서 PDF)을 확인할 수 있습니다. 참고자료는 국내 제품의 제형·함량에 맞춰 연결합니다.
- 기록은 해당 브라우저에만 저장됩니다. 새 통계는 기존 누적 기록에서 소급 생성하지 않습니다.


## 대시보드 화면 구성

- 최대 1,200px 콘텐츠 폭과 PC 2열 배치: 퀴즈·선택한 메뉴는 본문, 학습 요약·제품별 정답률·오답 안내는 오른쪽에 표시합니다.
- 상단 메뉴: 오늘의 퀴즈 / 제품별 연습 / 오답 노트 / 학습 현황.
- 제품별 연습은 제품 카드에서 바로 시작하거나 전체 제품을 선택해 시작할 수 있습니다.
- 메뉴 이동 시 진행 중인 연습을 보존하며, 제품별 연습의 ‘이어서 풀기’로 복원합니다. 일일 퀴즈로 돌아가기 버튼은 기존처럼 연습 세션을 종료합니다.
- 리더보드와 기록 초기화는 학습 현황 메뉴에 있습니다.
- 모바일에서는 한 열로 전환하며 질문과 답안을 먼저 보여줍니다.

## 진료지침 적용 문제 (2026-10-20 확인)

- 기존 50문제 및 저장된 문제 ID·정답은 유지합니다. 새 문제 ID는 200–219입니다.
- 제품별 연습에서 “가이드라인 문제만”을 선택하면 전체 20문제 또는 품목별 4문제를 연습할 수 있습니다. 일일 퀴즈에도 새 문제가 포함됩니다. 진행 중인 일일 세트는 저장된 ID를 유지합니다.
- 해설·완료 리뷰·오답 노트에 제품 허가사항과 진료지침을 구분해 표시합니다. 지침 판본, 발행 학회, 근거 위치와 확인일을 기록합니다.
- 지침은 성분·질환 단위 권고이며 특정 브랜드의 우월성·독점적 권고를 의미하지 않습니다. 제품의 국내 허가 범위와 별개입니다. 리리카 문제는 당뇨병성 신경병증, 쎄레브렉스 문제는 장기 NSAID 사용의 궤양 예방 범위입니다.
- 최신성은 확인일 기준 공개 자료로 판단하며 자동 갱신되지 않습니다. 쎄레브렉스 관련 궤양 예방 지침은 확인 가능한 공개 개정판이 2020년판이며, 2026년판으로 표시하지 않습니다.

- [이상지질혈증 진료지침 2026](https://www.lipid.or.kr/reference/guideline.php?boardid=guideline&mode=view&idx=1456) — 한국지질·동맥경화학회, 2026년판. 학회 공개 최신판: 2026-09-10 등록.
- [2026년 제6판 고혈압 진료지침](https://www.koreanhypertension.org/reference/guide?idno=10446&mode=read) — 대한고혈압학회, 2026년 제6판 수정본. 학회 공개 최신판: 2026-05-22 등록.
- [2025 당뇨병 진료지침](https://diabetes.or.kr/bbs/download.php?code=guide&number=1522) — 대한당뇨병학회, 2025년 제9판. 학회 공개 최신판: 2025년판.
- [약제 연관 소화성궤양의 임상 진료지침 개정안 2020](https://www.kjg.or.kr/journal/view.html?doi=10.4166/kjg.2020.76.3.108) — 대한상부위장관·헬리코박터학회, 2020년 개정판. 확인된 공개 개정판: 2020년. 해당 주제의 후속 국내 개정판은 확인되지 않음.


## 일일 문제 무작위 출제

- 브라우저의 난수로 새 세트의 시드를 생성합니다. 날짜만으로 고정된 동일 세트를 만들지 않습니다.
- 문제 ID와 순서를 저장해 중복 없이 최대 5문제를 출제합니다. 프로필 전환과 새로고침으로 세트가 바뀌지 않습니다.
- 업데이트 시 아직 답하지 않은 이전 고정 세트는 한 번만 무작위화합니다. 진행·완료한 기록과 점수는 보존합니다.
